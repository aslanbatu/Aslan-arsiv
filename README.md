# Aslan Arşiv — iPhone Web Uygulaması

Türkçe kişisel belge arşivi. PWA olarak Safari'den ana ekrana eklenebilir.

Özellikler:
- Klasör/alt klasör oluşturma, yeniden adlandırma ve silme
- Belge adını kullanıcı belirler
- Tüm arşivde belge adıyla arama
- Favoriler
- Kamera ile çok sayfalı yüksek çözünürlüklü tarama
- PDF oluşturma
- Fotoğraf/Dosyalar'dan içe aktarma
- PDF görüntüleme, paylaşma, indirme
- Yerel IndexedDB depolama
- Yedek dışa aktarma/geri yükleme
- PWA ikonları
